Build a crystal from two small arrays

Devin Gaughan · November 24, 2026 · 6 minute read

Every crystal structure in Titania, my browser-based lattice simulator, comes from the same two pieces of data. Once you see how that works, you can generate copper, silicon, or table salt with about thirty lines of JavaScript.

My background is in hardware and firmware, and crystal structure sits underneath all of it: the silicon in a chip is a diamond cubic lattice, and how that lattice is cut and doped decides how the device behaves. I wanted a tool that let me turn those structures around in my hands. This post walks through the core idea so you can build the same thing.

The idea: lattice plus basis

A crystal is a pattern that repeats in three directions. To describe one completely you need two things:

  • Lattice vectors. Three vectors that say how far to step, and in which direction, to reach the next copy of the pattern.
  • A basis. The atoms that sit inside one copy, written as fractional coordinates between 0 and 1.

Here is how Titania stores face-centered cubic, the structure of copper, aluminum, and gold:

fcc: {
  basis: [
    [0,   0,   0  ],
    [0.5, 0.5, 0  ],
    [0.5, 0,   0.5],
    [0,   0.5, 0.5],
  ],
  vectors: [
    [1, 0, 0],
    [0, 1, 0],
    [0, 0, 1],
  ],
  defaultA: 3.61,   // lattice constant in angstroms (copper)
}

One atom at the corner and one at the center of each of three faces. Those four positions, repeated, produce the whole metal.

From fractions to positions

To place the atoms, loop over the unit cells you want, add each cell's index to the basis coordinates, and multiply through the lattice vectors. This is a condensed version of the generator in Titania:

function generateLattice({ basis, vectors }, repeat, a) {
  const atoms = [];
  for (let i = 0; i < repeat; i++)
    for (let j = 0; j < repeat; j++)
      for (let k = 0; k < repeat; k++)
        for (const b of basis) {
          const f = [b[0] + i, b[1] + j, b[2] + k];
          atoms.push([0, 1, 2].map(axis =>
            a * (f[0] * vectors[0][axis] +
                 f[1] * vectors[1][axis] +
                 f[2] * vectors[2][axis])
          ));
        }
  return atoms;
}

With repeat = 2, the FCC entry above gives 2 × 2 × 2 cells of 4 atoms each, so 32 positions. Because the multiplication goes through the lattice vectors instead of assuming a cube, the same function handles hexagonal structures, where the vectors are not at right angles.

The full version in the repository also subtracts an offset to center the crystal on the origin, and it rounds each position into a string key so that no atom is ever placed twice.

Drawing the bonds

Bonds need no extra data. Two atoms are bonded if they are nearest neighbors, and the nearest-neighbor distance follows from geometry. In FCC it is half of a face diagonal:

const maxBond = a * Math.SQRT2 / 2 * 1.05;   // 5% tolerance

for (let i = 0; i < atoms.length; i++)
  for (let j = i + 1; j < atoms.length; j++)
    if (distance(atoms[i], atoms[j]) <= maxBond)
      bonds.push([atoms[i], atoms[j]]);

For copper that cutoff is about 2.55 Å before the tolerance, and every interior atom ends up with 12 bonds, which is the coordination number a textbook will give you. The pair loop is quadratic, which is fine at the few hundred atoms a browser scene shows.

Slicing along a plane

The same three vectors also give you lattice planes. Crystallographers name a plane by its Miller indices (hkl), and the spacing between parallel planes comes from the reciprocal lattice:

const vol = dot(a1, cross(a2, a3));
const b1 = scale(cross(a2, a3), 1 / vol);
const b2 = scale(cross(a3, a1), 1 / vol);
const b3 = scale(cross(a1, a2), 1 / vol);

const G = add(add(scale(b1, h), scale(b2, k)), scale(b3, l));
const dSpacing = 1 / magnitude(G);
const normal = normalize(G);

For a cubic crystal this reduces to d = a / √(h² + k² + l²). Silicon has a lattice constant of about 5.43 Å, so its (111) planes sit about 3.14 Å apart. That number is what an X-ray diffraction measurement picks up, and it is why Titania can draw a powder diffraction pattern from the same data that draws the atoms.

Try it

  1. Open the live app and pick FCC under Structure.
  2. Turn bonds on and raise Unit Cells to 3. Count the bonds on an atom in the middle.
  3. Switch to Diamond Cubic. The count drops to 4, and the tetrahedral shape of silicon appears.
  4. Under Lattice Planes, enter (111) and slide the plane position through the crystal.

Titania has 11 structures, including compounds such as rock salt and perovskite. Adding another means writing one more entry of vectors and basis. The source is on GitHub: devin-gaughan/titania.
